현재 온라인 웹 서비스는 Render.com의 무료 플랜(0.1 vCPU, 512MB RAM) 환경에서 호스팅되어 동작하고 있습니다.
단선율 및 4~8마디 내외의 악보는 정상 분석되지만, 마디 수가 많거나(다단 대보표 10마디 이상), 해상도가 높고 기호가 매우 밀집된 복잡한 악보의 경우 CNN 딥러닝 추론 시 클라우드 512MB 메모리가 초과(OOM Crash)되어 서버가 자동으로 재시작될 수 있습니다.
복잡한 악보를 메모리 한도 없이 무제한으로 초고속 인식·편집하고자 하실 경우, 아래 GitHub 저장소 코드를 내려받아 로컬 PC 환경에서 실행하시는 것을 적극 권장합니다.

GitHub 저장소 바로가기 git clone https://github.com/yjchoi101222/ai_steam.git && pip install -r requirements.txt && python -m uvicorn main:app --port 8000

💡연구 배경 및 목적

기존의 종이 악보는 연주자와 학습자에게 일방적인 시각 정보만을 제공하여, 초보자가 악보의 피치와 박자를 파악하고 실제 피아노 건반과 연동하여 학습하기에는 높은 진입 장벽이 존재합니다. 본 프로젝트 MuseAI는 스마트폰으로 악보 이미지를 찍어 업로드하는 것만으로, AI 기반 OMR 분석을 수행하고 가상 피아노 건반 및 소리와 완벽히 연동되는 인터랙티브 악보를 생성해 주는 다감각적 음악 학습 플랫폼을 구축하고자 하였습니다.

⚙️시스템 파이프라인 아키텍처 (4단계)

1

악보 이미지 전처리 (OpenCV)

기울어진 악보 각도를 수평 보정(Deskew)하고 CLAHE 및 적응형 임계값으로 이진화합니다.

2

OMR 기호 인식 엔진 (oemer AI)

합성곱 신경망(CNN) 딥러닝 모델이 음표, 빔, 쉼표 등 악보 요소를 판독하여 MusicXML을 추출합니다.

3

음악 이론 기반 교정 (music21)

중복 인식을 정제하고, 피아노 88건반 범위 조정 및 박자표 기준 마디 내 총 길이를 보정합니다.

4

인터랙티브 렌더링 & 연주 (OSMD & Web Audio)

정통 기보법으로 악보를 웹 캔버스에 시각화하고, 고음질 그랜드 피아노 사운드폰트로 소리를 출력합니다.

🌟연구 기대 효과

  • 다감각 악보 학습: 소리, 오선지 커서, 그리고 실시간 가상 피아노 건반(Piano Roll)이 완벽히 동기화되어 초보자의 피아노 학습 피드백을 가속합니다.
  • 편리한 편곡 및 편집: MuseScore와 같이 마우스 클릭 및 키보드 조작만으로 OMR 변환 과정에서 오인식된 음정을 빠르게 직접 수정하고 다운로드(XML/MIDI)할 수 있습니다.
  • 아카이빙 디지털화: 아날로그 종이 악보를 간편하게 검색 및 수정 가능한 디지털 음악 악보 데이터베이스로 즉시 보존합니다.
